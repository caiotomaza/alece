ALECE.

Backend inicial disponível. Este é o esqueleto técnico para desenvolver a interface ALECE de forma modular, segura e testável.

A interface financeira v1.32.1 está preservada em reference/prototype/ no repositório. Ainda não está conectada ao banco de dados.

Operação de desenvolvimento: use o Django Admin (somente usuário administrador) e os endpoints /health/live/ e /health/ready/.

Consulte README.md, RUNBOOK.md e docs/ para a implementação das funcionalidades financeiras.
