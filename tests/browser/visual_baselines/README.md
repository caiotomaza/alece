# Capturas aprovadas (repositório)

Somente PNGs de telas **reais** do ALECE, provenientes do job visual com
`ALECE_VISUAL_MODE=capture`, após revisão humana, devem ser versionadas aqui.

No modo padrão `compare`, ausência de PNG reprova o teste. Não copiar imagens
de `docs/acessibilidade/evidencias/`: são catálogos isolados, não telas Django.

Convenção: `<cenario>__<light|dark>__<320|390|768|1280|1920>.png`.

Consulte `docs/regressao-visual/MANUAL.md` antes de promover capturas.
